# First-reader journeys: Connecting the Dots

**Heuristic test plan, not a completed human study.** Automated browsers measure whether components work; they cannot prove comprehension. Ask five uninvolved non-specialists to perform these tasks in IT/EN/DE/FR at 390px mobile and desktop. Do not tell participants which menu to use.

| Task | Goal | Success criterion |
| --- | --- | --- |
| 1. Understand | Explain what a TLD is and distinguish it from a domain registration | Correct explanation using a simple dotted name |
| 2. Find Lugano | Find .lugano in Explorer | Identifies an applied-for string without assuming it is already delegated |
| 3. Count fairly | Compare 2012 and 2026 candidates | Explains 1,615 official applications, 1,614 public IDs and 2,783 rows including 1,169 replacements |
| 4. Investigate | Find a dispute and its evidence | Names an official source and identifies what remains uncertain |
| 5. Cite and download | Get the research release and technical dataset | Correctly identifies RR2 DOI, current v0.7.77 ZIP, historical v0.7.58 ZIP as different artifacts |

Record task completion, time, navigation errors, backtracks, wrong assumptions and optional participant feedback, without personal identifiers. An unfinished task counts as a failure.

**Release acceptance:** Do not claim 'tested with users' without real study results. Revisit labels and navigation if two or more independent participants fail the same task.
