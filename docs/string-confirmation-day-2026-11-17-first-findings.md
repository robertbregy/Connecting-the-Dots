# String Confirmation Day 2026 — first verified findings

Observed on 17 November 2026 after ICANN's String Confirmation Day announcement.

## Official ICANN snapshot

Source:
https://www.icann.org/en/announcements/details/icann-confirms-2026-round-applications-input-and-objections-period-begins-17-11-2026-en

ICANN reports, as of 16 November 2026:
- 1,610 applications proceeding.
- Nine applications withdrawn since Reveal Day.
- 152 applications switched to a replacement string.
- 287 applications were eligible to switch.
- 226 contention sets.
- 709 applications in contention.
- 50 Applicant Support Program applications.
- 333 brand applications.
- 16 community-based applications.
- 15 self-identified geographic applications.
- 22 IDN applications.
- Nine variant applications, including six variant-only applications.

Regional application counts:
- Africa: 16.
- Asia/Australia/Pacific: 215.
- Europe: 504.
- Latin America/Caribbean: 11.
- North America: 864.

## Reconciliation against Reveal Day

Reveal Day official snapshot (7 October 2026):
- 1,615 applications.
- Africa: 16.
- Asia/Australia/Pacific: 218.
- Europe: 506.
- Latin America/Caribbean: 11.
- North America: 864.
- 21 IDN applications.

ICANN states that nine applications were withdrawn after Reveal Day:
- seven in Asia/Australia/Pacific;
- two in Europe.

The regional arithmetic shows an unresolved but highly constrained transition:
- AP: 218 - 7 withdrawals = 211, yet String Confirmation Day reports 215.
- Europe: 506 - 2 = 504, exactly matching the new total.
- Other regions are unchanged.

Therefore the published totals imply four net additions to the AP application universe between Reveal Day and the 16 November snapshot, unless ICANN changed its counting methodology. This also reconciles the overall application count:
1,615 - 9 withdrawals + 4 additions = 1,610.

This is a project-derived reconciliation, not an ICANN-published explanation. The four application identities must be established from the updated APS export before publication as fact.

## WDO administrative-check application

APS still states that application WDO2627T-T45217 is undergoing administrative check and remains unavailable on the public Applications list.

Therefore WDO cannot presently be assumed to be one of the four implied post-Reveal additions.

## Replacement methodology correction

The frozen Reveal Day APS export contained:
- 1,169 replacement records;
- 442 replacement records with status Active;
- 727 replacement records with status Deactivated.

ICANN now states that only 287 applications were eligible to switch and 152 actually switched.

Consequently, the project must not equate an Active replacement-record status in the Reveal Day APS export with String Replacement Period eligibility. The prior 442 count remains a valid observed record-status count, but not an eligibility denominator.

## Contention transition

Frozen Reveal Day project evidence:
- 263 preliminary contention sets;
- 891 applications in those sets.

String Confirmation Day announcement:
- ICANN describes the pre-replacement comparison point as 262 contention sets and 885 applications in contention;
- after 152 replacement selections: 226 sets and 709 applications in contention.

A plausible sequence is:
1. Reveal Day: 263 / 891.
2. Withdrawals or other pre-confirmation application-universe changes: 262 / 885.
3. Replacement selections: 226 / 709.

This decomposition is analytically plausible but remains to be verified against the updated official contention-set file before being stated as fact.
