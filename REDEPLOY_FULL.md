# Connecting the Dots v0.7.1 — FULL REDEPLOY

This package is intended for a complete replacement of the GitHub repository contents.

## Clean redeploy
1. Keep the repository itself, but remove the existing project files from the `main` branch.
2. Upload **all files and folders contained in this ZIP root** to the repository root.
3. Do not upload the enclosing folder and do not upload the ZIP itself as the website.
4. Commit directly to `main`.
5. In Settings > Pages, keep the existing GitHub Pages source (normally `main` / root).
6. Wait for the Pages deployment to complete, then hard-refresh the public site.
